# ExpenseLeaf 🌿

A minimalist, mobile-first personal expense tracker designed for zero-friction daily logging and shared use. Built with a clean matte-black aesthetic and instant data persistence.

---

## ⚡ Tech Stack

- **Frontend:** React (Vite), Tailwind CSS
- **Icons & UI:** Lucide React
- **Charts & Insights:** Recharts, Date-fns
- **Backend & Database:** Supabase (PostgreSQL with Row Level Security)
- **Deployment:** Vercel

---

## ✨ Features

- **3-Second Entry:** Slide-up bottom sheet with streamlined UPI and Cash payment modes.
- **PIN-Based Access:** Fast numeric keypad authentication with persistent local login state.
- **Dynamic Budgets:** Fully editable monthly and category limits stored per user via JSONB.
- **Actionable Analytics:** 
  - Dynamic monthly burn rate and safe daily spend pacing.
  - Category breakdown visualization.
  - Weekday vs. weekend spending distribution.
- **Category Drill-Down:** Filterable daily expense log with inline deletion.
- **PWA Ready:** Formatted for fullscreen mobile home screen installation.
